Threat Modeling

Cyber Kill Chains

The cyber kill chain is a model that explains the stages of a cyber intrusion. It helps defenders think in terms of attacker progression and interruption points rather than isolated alerts.

Core concepts

Reconnaissance

The adversary studies the target, learns the environment, and identifies weaknesses, services, and user patterns.

Weaponization

The attacker combines an exploit with a payload or malicious file that can be delivered to the target.

Delivery

The malicious payload reaches the victim through phishing, websites, removable media, or compromised software.

Exploitation

The target system runs the malicious code or takes advantage of a vulnerability to establish execution.

Installation

The attacker establishes persistence, implants malware, or reuses existing compromised credentials.

My notes

Write down interruption points, telemetry, and response questions for each stage.

Key takeaways

  • Interrupting the kill chain early can stop an intrusion before it becomes damaging.
  • Detection should focus on key transition points between stages.
  • The chain is useful for response planning, not just theory.
