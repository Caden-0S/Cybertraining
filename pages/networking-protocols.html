Networking

Networking Protocols

Networking protocols are the rules that govern how computers talk to each other. In security work, understanding the protocol stack helps you identify unusual traffic, weak handshakes, spoofing, and protocol abuse.

Core concepts

TCP/IP

The TCP/IP suite is the foundation of modern networking. IP handles addressing and routing, while TCP provides reliable, ordered data delivery and UDP provides low-overhead connectionless transfer.

DNS

DNS converts names to IPs and is often abused for command-and-control, data exfiltration, and domain generation. Look for odd query patterns, high-volume lookups, and suspicious TLDs.

HTTP/HTTPS

HTTP is the application layer protocol used by web traffic. HTTPS adds TLS encryption, making protocol inspection harder but not impossible when TLS termination or analytics are enabled.

ARP and Layer 2

ARP maps IP to MAC addresses and can be abused in local network attacks such as ARP poisoning. Security analysts look for duplicate responses, strange broadcasts, and unexpected gateway changes.

Key takeaways

  • TCP provides reliability; UDP is faster and lighter.
  • DNS is often the easiest place to spot attacker infrastructure.
  • TLS hides payload content but not all metadata patterns.
  • Switching, routing, and segmentation reduce lateral movement risk.
