Interview preparation

Practice

Turn knowledge into concise, structured analyst answers. Use these prompts to rehearse how you would investigate, classify behavior, communicate risk, and recommend action with confidence.

Explain the alert

Describe how you would triage a suspicious PowerShell alert from first signal to confirmed or dismissed incident. Strong answers show a clear decision path, not just a conclusion.

  • What context would you gather first: user identity, asset ownership, process lineage, or command-line telemetry?
  • Which related events would you correlate: EDR, authentication logs, firewall logs, DNS, or proxy telemetry?
  • How would you assess whether this is malicious, benign automation, or a false positive?
  • How would you communicate confidence, scope, and impact to a stakeholder or incident lead?

Model approach: Start with the asset and user context, establish whether the process is expected, then correlate additional logs to determine if it is isolated or part of a broader intrusion sequence.

Map the behavior

Choose one behavior from the topic pages and explain its tactic, technique, evidence sources, and likely defensive control. The best answers connect the activity to the adversary’s objective.

  • State the attacker objective in plain language.
  • Name the telemetry that supports the mapping.
  • Explain what it would look like at each stage of the lifecycle.
  • Suggest one prevention measure and one detection measure.

Example structure: “This behavior suggests credential access followed by lateral movement because the host performed an abnormal authentication pattern and then connected to a new service account target.”

Prioritize response

Imagine a user receives a phishing email, clicks a link, and an office application launches a script that creates a scheduled task. Explain how you would contain the incident while deciding whether to isolate, block, or collect evidence.

  • What would you isolate first?
  • What evidence must you preserve before cleaning up the endpoint?
  • How would you identify whether the malicious behavior is a single host event or a wider campaign?
